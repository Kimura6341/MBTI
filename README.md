# 人格光谱

中文原创人格探索原型。使用原生 HTML、CSS 和 ES Modules，无运行时依赖。60 道原创题、五维等权评分、十组答题、进度恢复、答案校验、结果解释、评分明细、文本下载和打印。

## 运行

在本目录执行 `node preview.mjs`，打开 http://127.0.0.1:4173 。验证评分执行 `node --test tests/model.test.mjs` 。部署静态目录为 `dist/`。

## 评分边界

这是自行编写的探索性问卷，不是16Personalities、NERIS或官方MBTI。每维12题，正反各6题，每题权重1。答案为+3到-3，反向题反转；百分比按 `round(50+50*S/36)` 换算，不是人口百分位。零分显示X。靠近中点8个百分点的提示阈值是产品约定。未完成心理测量学验证。

答案只写入本浏览器localStorage。不设置第三方追踪脚本，不将答案传给服务端。

## 原站调查

已确认原站当前可见前6题的选项编码为-3至+3，不能据此认定其题目权重。公开脚本调查记录另见工作区输出；没有将原站代码或题库加入此产品。
